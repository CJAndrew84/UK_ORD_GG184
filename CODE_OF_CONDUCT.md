# Code of Conduct

This project follows the principle: *“Be kind, be clear, be constructive.”*

## Our Standards
We want this project to be an open, collaborative, and respectful space for everyone — whether you’re a CAD manager, a graduate engineer, or just curious.

Examples of positive behavior:
- Offering constructive feedback.
- Asking questions with context and patience.
- Sharing practical knowledge openly.
- Giving credit where it’s due.

Unacceptable behavior includes:
- Personal attacks, insults, or trolling.
- Sharing proprietary or confidential information.
- Spamming or self-promotion unrelated to the project.

## Enforcement
- Moderation is light-touch: we’ll reach out first before taking any action.
- Repeated violations may result in PRs or issues being closed.

## Attribution
This Code of Conduct is adapted from the Contributor Covenant (v2.1) but rewritten in plain UK English for a more practical tone.
