The Asset Manager is a Technology Preview. This tool should not be used in a production environment at this time.

The Sample_AssetDefinitions files provided in this folder are examples 
 that can be useful for exploring and providing feedback 
 on this Technology Preview tool.

The configuration variable ITEMTYPE_EXCELLOOKUP must be defined pointing to the full path and file name of the Asset Management Lookup.xlsx file.

There is a recorded presentation available on the Learn Server that explains and demonstrates these spreadsheet files.
The presentation is located at https://learn.bentley.com/app/VideoPlayer/LinkToIndividualCourse?LearningPathID=112668&CourseId=127203&MediaID=5017577
