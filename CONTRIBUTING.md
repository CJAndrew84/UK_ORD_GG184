# Contributing to UK_ORD_GG184

First off – thank you for taking the time to contribute!  
This project exists to make UK OpenRoads Designer setups usable, consistent, and transparent for everyone.

## 🧩 How to Contribute
1. **Fork** the repository.
2. **Create a branch** for your feature or fix.
3. **Test** your changes locally (load the workspace in ORD to verify configuration).
4. **Commit** with clear messages (e.g., `Added new FD for CC/CP480 structures`).
5. **Submit a Pull Request** with a short description of what you changed and why.

## 🧠 Guidelines
- Keep file and variable naming consistent with BS 1192 / ISO 19650.
- All Feature Definitions and Levels should trace back to SHW or Uniclass codes.
- When adding new CSV mappings, ensure headers remain identical to existing schema.
- Always update the README or relevant documentation if your change affects setup or usage.
- Avoid including licensed content (e.g., DMRB figures) directly in the repo.

## 🧪 Testing
- Open the workspace in ORD (10.12+).
- Confirm Feature Definitions, Annotation Groups, and DGNLIBs load correctly.
- Run sample report templates to confirm item type mapping.

## 💬 Need Help?
Open a Discussion or Issue in GitHub if:
- You’re unsure about configuration variables.
- You want to propose new functionality.
- Something doesn’t load as expected.
